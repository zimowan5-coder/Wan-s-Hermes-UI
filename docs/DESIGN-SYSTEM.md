# Hermes UI 设计系统（v0.4）

> 目标：Apple 级交互品质的 Windows AI 桌面工作台设计语言。
> 学习 Apple 的设计原则（克制、一致、动效服务于理解），**不复制** macOS 外观、商标与窗口控件。
> v0.4 新增：基于 Apple HIG 哲学（Clarity 清晰 / Deference 顺从 / Depth 纵深）的整体重设计，
> 收敛 v0.3 过度使用的玻璃与边框，回归"内容优先、界面退后"。

## 0. v0.4 重设计：审计结论与方向

**审计发现（2026-10-13，六视图走查）：**

1. 面板嵌套过多：悬浮顶栏 + 悬浮导航 + 内容卡片 + 卡片内描边元素，层层相套，违反 v0.2"页面内不做卡片套卡片"原则。
2. 边框密集：卡片、按钮、输入框、chip 几乎处处描边；Apple 的成熟做法是用留白与分组表达结构，而非线框。
3. 毛玻璃过度：顶栏/导航/气泡/审批卡/命令面板全是玻璃材质，互相打架，没有主次。
4. 顶栏信息过载：一行塞进 logo、MOCK、主题切换、命令、连接、Profile、审批 7 组控件。
5. 圆角不统一：999px / 24px / 20px / 16px / 12px / 8px 混用，无系统。
6. 列表视图（任务/技能/记忆/消息）每行独立卡片+阴影，视觉噪音大；应为 iOS 式分组列表：一个圆角容器 + 内部分割线。
7. 视图标题区：标题 + 大段说明文字平级排列，说明文字喧宾夺主。

**v0.4 方向（对应 Apple HIG 三原则）：**

- **Clarity**：内容优先。列表去卡片化（分组列表）；按钮去边框化（主按钮实心、次要按钮纯文本/浅灰填充）；输入框去描边（浅灰填充 iOS 式）。
- **Deference**：界面退后。玻璃只保留给真正的浮层（命令面板 Spotlight 式）；顶栏/导航/内容全部实色；装饰性渐变只留极淡的环境光。
- **Depth**：纵深靠克制的 elevation（浮层阴影）表达，不靠到处描边。
- **排版**：建立 type scale（大标题 20/700/-0.01em、正文 14、次要 13/12），标题字距收紧，行高 1.5–1.6。
- **圆角系统**：统一为 8（小控件）/ 12（卡片）/ 16（大面板）/ 999（胶囊按钮），废除 20/24/28 的随意使用。
- **深色主题精心设计**（非反转）：基底 `#0e0e11`、表面 `#1a1a1e`、分割线 `rgba(255,255,255,.08)`、
  主蓝 `#5e9bff`、正文 `#f5f5f7`、次要 `#a1a1a6`——接近 Apple 原生深色的质感。
- **顶栏瘦身**：48px slim toolbar + 底部 hairline；右侧只留命令、连接、审批三个高频控件，
  主题切换收进设置（顶栏保留精简版），Profile 合并进连接状态区。
- **动效**：150–250ms ease-out，保持 `prefers-reduced-motion` 降级；只用于状态变化。

**QA 钩子**（截图/走查用，不影响产品行为）：
- `?theme=light|dark|system` —— 强制主题
- `?view=tasks|skills|memory|messaging|settings` —— 直达某视图
- `?notransition=1` —— 禁用 body 主题过渡，避免深色截图抓到 200ms 切换中间帧
  （教训：主题在 React effect 里后应用，无此钩子时 `?theme=dark` 必闪白；见 AGENTS.md）

## 0. v0.3 Liquid Glass 材质规范（已收敛，仅命令面板保留）

**三要素**（对应 Apple 提出的 Transparency / Depth / Motion，Web 实现）：

1. **透明度**：`--glass-bg` 高通透配方（浅色 `rgba(255,255,255,0.45)` / 深色 `rgba(22,27,43,0.45)`）；
   可读性关键表面（命令面板、对话框、输入框）用 `--glass-bg-strong`（0.72/0.74）。
2. **景深**：`backdrop-filter: blur(28px) saturate(190%)`（深色 160%），玻璃浮于内容之上；
   页面底色带极淡环境色晕（蓝 7% / 红 5%），给玻璃提供可折射的内容，对比度不受影响。
3. **光效**：1px 内嵌顶部高光（`--glass-edge`）模拟透镜边缘反光 + 柔和投影；
   无障碍：玻璃上的文字组合仍满足 WCAG AA（环境晕极淡，模糊后底色接近基底）。

**形态**：按钮 / 导航项 / 输入框 / 顶栏胶囊化（`border-radius: 999px`，`.glass-capsule`）；
面板用 `--radius-xl/2xl` 大圆角；悬浮 chrome（顶栏、导航）脱离边缘、带 10–14px 外边距。

**应用清单**：顶栏悬浮玻璃条、导航悬浮玻璃面板、命令面板（`glass-strong`，顺带修复未定义的 `--bg-primary`）、
聊天输入框（胶囊 + 聚焦光晕）、助手气泡（`glass`）、审批卡（`glass-strong`）、slash 菜单（`glass-strong`）。
`prefers-reduced-motion` 下保持原有降级；`backdrop-filter` 不支持时回退为纯色（`@supports` 外的渐进增强由 tokens 天然覆盖）。

## 1. 设计原则

1. **语义先于装饰**：颜色只表达含义（背景/前景/强调/状态），不做装饰性渐变与大面积高饱和色块。
2. **克制的层次**：信息分组用 4px 刻度的间距 + 一根细分割线；阴影只出现在浮层（`--shadow-lg`），页面内不做"卡片套卡片"。
3. **动效服务于理解**：120–240ms、ease-out；只用于状态变化与过渡，不做循环装饰动画；完整支持 `prefers-reduced-motion`。
4. **键盘优先可达**：所有交互都可键盘操作；全局可见焦点环（WCAG 2.4.7）；不劫持焦点、不抢焦点。
5. **诚实的状态**：每个异步状态（思考中/执行中/待审批/完成/失败/断连）都有明确视觉表达，不用"假成功"掩盖。

## 2. 主题

三种模式：`light` / `dark` / `system`（默认跟随 Windows 系统主题）。

- 运行时切换：顶栏三段式切换器；`system` 模式监听 `prefers-color-scheme` 实时跟随。
- 持久化：`localStorage['hermes-ui-theme']`；写入失败（隐私模式）时仅本次生效。
- 实现：`src/theme/theme.tsx` 的 `useTheme()` 解析后写入 `<html data-theme>`；CSS 只定义 `:root`（浅）与 `:root[data-theme="dark"]`（深）两套 tokens。
- 调试钩子：URL 参数 `?theme=light|dark|system` 覆盖本次主题（仅用于 QA/截图，无后端）。

浅色避免纯白刺眼（基底 `#f6f7f9`），深色避免纯黑压抑（基底 `#16181d`）。两套主题信息架构与组件行为完全一致。

### 3.3 间距 / 圆角 / 动效 / 阴影

- 间距：4px 基础刻度（4/8/12/16/20/24…），组件内边距优先 8/12/16。
- 圆角：`--radius-sm 8` / `--radius-md 12` / `--radius-lg 16` / `--radius-xl 20`。
- 动效：`--motion-fast 120ms`（hover/色值）、`--motion-normal 200ms`（显隐/位移）、`--motion-slow 240ms`（卡片入场）；`--ease-out: cubic-bezier(0.2,0.7,0.3,1)`。
- 阴影：`--shadow-sm/md` 用于控件与小浮层；`--shadow-lg` 仅用于 Dialog/审批卡等需要"浮起"的元素。
- 字体：`system-ui, "Segoe UI", "Microsoft YaHei", "PingFang SC"` —— Windows 优先，中文排版行高 1.6。

## 4. 组件约定

- **一个组件类只用 tokens**：禁止在组件内写裸色值；需要新语义先加 token。
- **焦点**：`:focus-visible` 全局 2px accent 焦点环；`--motion` 全部走变量。
- **Mock 标记**：原型中一切模拟数据用 `.mock-badge`（虚线描边 + MOCK 字样），不得移除。
- **状态表达**：`chip` 承载状态文本；颜色只做辅助，文字永远在场（色盲友好）。

## 5. 可访问性基线（WCAG 2.2 AA）

- 对比度见 §3.2；新增颜色组合必须先计算。
- 键盘：Tab 顺序符合视觉顺序；Enter/Space 激活；Esc 关闭浮层/取消编辑；审批等关键操作可达且可撤销。
- 焦点不被抢占：异步更新（消息流、工具结果）不移动焦点；`aria-live="polite"` 播报状态变化。
- `prefers-reduced-motion` 下禁用非必要的动画与过渡。
- 触控目标 ≥ 24×24px（导航项/按钮满足）。
