2. 旧视图（任务/技能/记忆/消息/设置）经 `--ui-*` 别名自动适配双主题，未逐页精修。
3. 全部仍为 MOCK 数据；审批/重试只改本地状态，刷新重置。
4. CI 为新增，待 push 后首次运行结果。**受阻**：`.github/workflows/ci.yml` 无法经当前 GitHub App 推送（缺 `workflows: write` 权限，API 返回 403），文件已备好在本地 `prototype/.github/workflows/ci.yml`（实际路径 `.github/workflows/ci.yml`），需你二选一：(a) 在 GitHub 网页上手动新建该文件粘贴内容；(b) 给 Meta Muse AI GitHub App 补上 workflows 写权限后我重推。
