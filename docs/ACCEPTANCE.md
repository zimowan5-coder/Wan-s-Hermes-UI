# 交互与可访问性验收清单（第二阶段）

> 范围：双主题设计系统 + 聊天主界面重构。全部基于模拟数据。

## 主题系统

- [x] 三种模式：浅色 / 深色 / 跟随系统（默认），顶栏三段式切换器
- [x] 跟随系统：`useTheme()` 监听 `prefers-color-scheme`，系统切换主题时应用实时跟随
- [x] 持久化：`localStorage['hermes-ui-theme']`；写入失败时仅本次生效
- [x] 两套主题信息架构与组件行为一致（同一套组件 + tokens）
- [x] 无纯白/纯黑基底、无大面积强烈渐变
- [x] `?theme=light|dark|system` QA 覆盖参数可用（截图用）

## 聊天主界面

- [x] 左导航 rail 可折叠（64px 图标栏 / 208px 全宽），偏好持久化
- [x] 会话列表可折叠；折叠后保留"展开"与"新会话"入口
- [x] 消息列阅读宽度 760px 居中，行高 1.6
- [x] Composer：Enter 发送、Shift+Enter 换行、Esc 取消聚焦；禁用态（断连）明确
- [x] Agent 状态机：思考中 / 工具执行中 / 等待审批 / 就绪 / 失败，`aria-live="polite"` 播报
- [x] 工具时间线可折叠，失败项标红、可重试（模拟）
- [x] 审批卡：低/中风险一次点击；**高风险两步确认**（二次确认 + 可取消）；已处理卡片变为只读状态
- [x] 会话切换有过渡动画（`view-enter`，200ms）
- [x] 空状态（新会话）：插画位 + 建议问题，一键填入输入框
- [x] 加载状态：发送中"正在输入"指示器
- [x] 错误状态：失败工具消息标红 + 重试按钮（模拟）
- [x] 断连状态：顶栏连接开关（模拟）→ 聊天顶部红色横幅 + 输入禁用
- [x] 原生功能入口保留：会话管理、审批、工具时间线、Profile 切换均在

## 可访问性（WCAG 2.2 AA）

- [x] 对比度：正文/次要/辅助/强调色在双主题下全部 ≥ 4.5:1（见 DESIGN-SYSTEM.md §3.2 实测表）
- [x] 全局 `:focus-visible` 2px 焦点环；Tab 顺序符合视觉顺序
- [x] 审批按钮、主题切换器、折叠按钮均有 `aria-label` / `aria-pressed` / `aria-expanded`
- [x] 状态变化经 `role="status"` + `aria-live="polite"` 播报，不抢夺焦点
- [x] 颜色只做辅助：状态同时有文字标签（色盲友好）
- [x] `prefers-reduced-motion: reduce` 下禁用动画与过渡
- [x] 触控目标 ≥ 24px（导航项 36px+、按钮满足）

## 工程

- [x] `tsc --noEmit` + `vite build` 通过
- [x] 计时器清理：`timerRef` 在卸载与切换会话时清除
- [x] 媒体查询监听器在 `useTheme` 卸载时移除
- [x] 时钟 `setInterval` 清理；窗口尺寸变化由 flex 布局自适应
- [x] 硬编码修复：审批数改为动态派生；底部时间改为实时时钟
- [x] 未动 butler、未动 Hermes 后端、无密钥、无 main 直推

## 已知限制

1. 浏览器沙箱无法访问本地回环地址，可视化 QA 改用本机 headless Chromium 真实截图（见 `docs/screenshots/`）

3. 审批"批准/拒绝"只改本地 mock 状态；重试按钮无真实动作
4. 仅深色单图/浅色单图两张截图；交互录屏未做
