# 功能入口对照表 · 官方 Hermes Desktop → 新界面（v0.8）

研究基线：`NousResearch/hermes-agent` `apps/desktop`（2026-10-18，提交 `5fc490e2`）。
依据：路由 `src/app/routes.ts`、中文文案 `src/i18n/zh.ts`、默认快捷键 `src/lib/keybinds/actions.ts`。
新界面里所有数据仍是演示内容，不连接真实 Hermes。

## 一、整体结构怎么变

| | 官方 | 新界面 |
|---|---|---|
| 左侧 | 一列：顶部 5 个入口 + 会话列表（置顶 / 最近 / 按项目分组） | 一列：新建会话 + 5 个入口 + 会话列表（置顶 / 最近），左下角头像菜单 |
| 设置、命令中心、配置档案、智能体、记忆图谱、会话导入 | 全屏浮层，入口散在顶栏图标、命令面板、快捷键 | 头像菜单集中收纳；命令面板全覆盖；快捷键与官方一致 |
| 开发者面板（文件 / 终端 / 审查 / 浏览器 / 日志） | 「简洁 / 高级」界面模式控制 | 同样两种模式，默认简洁；高级模式顶栏出现右侧面板按钮 |
| HUD、宠物、布局编辑器 | 顶栏图标 / 命令面板 | 收进 设置 › 外观（命令面板也能搜到） |

## 三、本轮没有做的（如实记录）

- 多标签 / 分屏 / 新窗口打开会话、工作树（worktree）与「打开文件夹为项目」：属于开发者工作流，只在命令面板和会话菜单里保留入口（演示提示），没有做真正的多窗口。
- 首次启动引导、安装器、账单与套餐页、宠物生成器：入口保留在设置里，内容为占位说明。
- 浏览器内嵌、终端交互：右侧面板展示的是演示内容，不能真的执行命令。
